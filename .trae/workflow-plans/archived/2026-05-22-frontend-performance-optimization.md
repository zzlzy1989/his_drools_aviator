## 1. 问题分析

### 1.1 当前症状

- 点击模块时短暂白屏
- 首次访问模块响应慢
- 路由切换时页面闪烁

### 1.2 根本原因

| 问题 | 原因 | 影响 |
|------|------|------|
| AntV X6 (419KB) | 规则流设计器组件过大 | 首屏加载延迟 |
| Monaco Editor | 代码编辑器体积大 | 懒加载时间长 |
| Element Plus | 全量导入未按需加载 | 初始包体积大 |
| 路由懒加载 | 每个模块独立 chunk | 首次访问需下载 |
| CSS 导入 | 全量 CSS 加载 | 样式加载慢 |
