# Memory - 会话记忆系统

> 每日工作笔记，用于跨天任务衔接和知识回写素材收集

---

## 使用方法

### 创建日记
1. 复制 `TEMPLATE.md`
2. 重命名为当天日期: `2026-04-25.md`
3. 按模板填写内容

### 何时创建
- 开始一个较大的开发任务时
- 需要跨多天推进的功能时
- 发现值得记录的知识时

### 知识回写触发
任务完成后，使用 `((command:knowledge-writeback))` 触发三问自省：
1. 暴露了哪些未明确的业务假设？
2. 代码做了什么但没说清楚为什么？
3. 有没有和现有知识冲突？

将答案中值得持久化的内容更新到:
- `domain/glossary.md` — 新术语
- `domain/rules.md` — 新业务规则
- `domain/decisions.md` — 新决策记录
- `domain/edge-cases.md` — 新边界情况
- `MEMORY.md` — 项目事实更新
