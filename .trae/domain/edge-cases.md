# edge-cases.md - HIS 动态规则中台

> 记录编码和测试中发现的特殊边界情况，防止遗漏

---

## EC-01: 空规则集操作

**场景**: 租户下没有任何生效规则时的操作

| 操作 | 预期行为 | 当前处理 |
|------|---------|---------|
| 规则匹配 | 返回空匹配列表（非异常） | ✅ 正常 |
| 发起结算 | 提示"无可用的结算规则" | ✅ 正常 |
| 导出规则报告 | 返回空报告或提示无数据 | ⚠️ 需确认 |
| 删除空规则组 | 允许删除（级联无影响） | ✅ 正常 |

## EC-02: 并发规则更新冲突

**场景**: 管理员同时修改同一个规则

| 变量 | 行为 |
|------|------|
| 最后写入胜出 (Last Write Wins) | ✅ 当前策略（简单） |
| 乐观锁 (version 比较) | ⬜ 待实现（推荐） |
| 分布式锁 (Redisson) | ❌ 不推荐（性能差） |

**影响范围**: RuleDefinition, Formula, SettlementConfig

## EC-03: 大量规则加载边界

**场景**: 单个租户规则数量超过 10,000 条时的行为

| 边界值 | 预期 |
|--------|------|
| Drools KIE Base 编译时间 | >1000 条规则需异步编译 |
| 规则内存占用 | 估算每条规则 ~2KB，监控 JVM 内存 |
| 规则匹配性能 | 使用 ReteOO 算法，复杂度 O(n)→O(log n) |
| 热更新频率限制 | 最小间隔 10s，防止频繁重建 KIE Base |
| 规则分页查询 | 支持，默认 20 条/页 |

## EC-04: Aviator 表达式特殊输入

**场景**: 公式计算中的特殊值和字符

| 输入类型 | 示例 | 预期处理 |
|---------|------|---------|
| 除零操作 | `1/0` | 返回 Infinity 或抛出 ArithmeticException |
| 空值参与运算 | `null + 100` | 返回 null 或按配置返回 0 |
| 超大数值 | `99999999999999.99` | BigDecimal 自动处理，注意精度丢失 |
| 负数金额 | `-100.00` | 允许（退费场景），需特殊标记 |
| NaN 传播 | `0/0 * 100` | 结果为 NaN，需前置校验 |
| 嵌套括号层级 | 50+ 层嵌套 | Aviator 支持但需关注栈深度 |
| 特殊函数调用 | `sys.date()` | 白名单内的允许，否则拒绝 |

## EC-05: 循环引用与递归

**场景**: 规则/公式间的相互引用

| 场景 | 是否存在 | 处理方式 |
|------|---------|---------|
| 规则 A 引用规则 B，B 又引用 A | ✅ 可能存在 | 编译时检测循环依赖，拒绝加载 |
| 公式 A 调用公式 B，B 又调用 A | ✅ 可能存在 | 调用深度限制 ≤ 3 层 |
| 规则调用公式，公式又触发规则 | ✅ 存在 | Agent 调度层控制总深度 ≤ 5 层 |
| Skill 自调用 | ❌ 禁止 | 执行时检测并拒绝 |

## EC-06: 金额计算精度边界

**场景**: 医保结算中的精度问题

| 边界 | 预期 |
|------|------|
| 四舍五入模式 | HALF_UP（银行家舍入可配置） |
| 小数位位数 | 默认 2 位，可配置 0-6 位 |
| 连续计算精度损失 | `((100/3)*3)` 应等于 100，使用中间精度 10 位 |
| 跨币种转换 | 汇率使用 BigDecimal，保留 6 位小数 |
| 极大金额 | 支持 max 16 位整数 + 4 位小数 |
| 负零值 | `-0.00` 应规范化为 `0.00` |

## EC-07: 时间相关边界

**场景**: 涉及时间的规则判断

| 边界 | 预期 |
|------|------|

| 跨年结算 | 年末就诊次年结算，费率按就诊时间 |
| 起付线累计周期 | 自然年度（1月1日重置） |
| 规则有效期 | 支持 begin_date ~ end_date，边界包含 |
| 公式中的日期函数 | `now()` 取服务器时间，`biz_date()` 取业务时间 |

## EC-08: 多租户隔离边界

**场景**: 租户间的数据隔离特殊情况

| 场景 | 预期行为 |
|------|---------|
| 超级管理员查看跨租户数据 | 允许（只读），操作需明确指定 tenant_id |
| 租户 A 尝试访问租户 B 规则 | 拒绝（403 Forbidden） |
| 共享规则模板复制 | 允许（复制为新规则，非共享引用） |
| 租户资源配额耗尽 | 拒绝新规则创建，提示升级套餐 |
| 租户删除后数据归属 | 归档保留，超期清理 |

## EC-09: 规则热更新边界

**场景**: Nacos/Apollo 配置推送的特殊情况

| 边界 | 预期 |
|------|------|
| 推送网络中断 | 本地版本继续生效，重连后拉取最新 |
| 推送内容格式错误 | 校验失败，保持当前版本，告警通知 |
| 并发推送多个规则 | 按顺序处理，每个规则独立更新 |
| 推送版本回退 | 支持，从 snapshot 表恢复 |
| 全量推送 vs 增量推送 | 支持两种模式，增量更高效 |
| 推送期间正在执行的结算 | 使用旧规则完成，新规则下次生效 |

## EC-10: 高并发结算边界

**场景**: 大批量结算请求同时到达

| 边界 | 预期 |
|------|------|
| 并发结算上限 | 可配置（默认 50），超出排队 |
| 同一就诊重复结算 | 幂等校验，返回已有结果 |
| 结算队列满 | 返回 503 Service Unavailable |
| 部分结算失败 | 记录失败项，支持批量重试 |
| 数据库连接池耗尽 | 等待超时后返回错误，不丢数据 |
| Redis 缓存击穿 | 本地 Caffeine 二级缓存兜底 |

## EC-11: Skill/Agent 执行边界

**场景**: Skill 和 Agent 调度的异常情况

| 边界 | 预期 |
|------|------|
| Skill 执行超时 | 终止线程，返回超时错误，记录日志 |
| Agent 决策死循环 | 最大步骤数限制（默认 100 步） |
| Skill 依赖的外部服务不可用 | 降级返回默认值或跳过该 Skill |
| Skill 返回结果格式异常 | 解析失败，记录原始返回，标记异常 |
| 并发 Skill 数超限 | 排队等待，超时后拒绝 |
| Skill 间数据传递过大 | 限制 1MB，超截断 |

## EC-12: 数据导入导出边界

**场景**: 规则/公式的导入导出操作

| 边界 | 预期 |
|------|------|
| 导入文件为空 | 提示文件内容为空 |
| 导入文件格式错误 | 返回具体错误行号和原因 |

## EC-14: 安全攻击边界

**场景**: 恶意输入和攻击尝试

| 攻击类型 | 示例 | 预期处理 |
|---------|------|---------|
| Aviator 注入 | `Runtime.getRuntime().exec('rm -rf /')` | 白名单拦截，仅允许数学/逻辑函数 |
| DRL 注入 | 在 rule 中嵌入 Java 代码块 | 语法层面禁止 eval/mvel |
| XSS（管理后台） | `<img onerror=alert(1)>` | 前端转义 + 后端 HTML Encode |
| SQL 注入 | `' OR 1=1 --` | MyBatis/JPA 参数化查询防护 |
| SSRF | 规则中请求内网地址 | 网络策略白名单限制 |
| DoS | 恶意大量规则匹配请求 | 限流 + IP 黑名单 |

## EC-15: RuleFlow 流程编排边界

**场景**: 流程节点编排的特殊情况

| 边界 | 预期 |
|------|------|
| 无 start 节点的流程 | 校验拒绝保存 |
| 无 end 节点的流程 | 校验拒绝保存 |
| 流程节点形成环 | 校验检测并拒绝（避免死循环） |
| 孤立节点（无入边无出边） | 校验警告提示 |
| 流程节点条件全为 false | 流程执行到分支末尾终止 |
| 节点引用的规则不存在 | 运行时降级为跳过该节点 |
| 节点引用的公式不存在 | 运行时返回零值并告警 |

## EC-16: DRG 分组边界

**场景**: DRG 入组的特殊情况

| 边界 | 预期 |
|------|------|
| 无主诊断编码 | 无法入组，走默认结算规则 |
| 主诊断不在 MDC 范围 | 入组失败，返回未分组 |
| 多手术编码优先级 | 按手术权重排序，取最高 |
| DRG 权重为零 | 允许（特殊病种），结算时提示 |
| 历史 DRG 版本不兼容 | 使用就诊时间对应版本的分组规则 |
| DRG 定义缺失 | 降级为按项目付费模式 |

## EC-17: 合理用药审核边界

**场景**: 用药审核的特殊情况

| 边界 | 预期 |
|------|------|
| 药品不在目录中 | 标记为目录外，提示自费 |
| 药品已停产 | 返回替代药品建议 |
| 患者过敏史缺失 | 跳过过敏检查，记录 WARN |
| 配伍禁忌表数据为空 | 跳过配伍检查，返回 PASS |
| 处方超大（100+ 种药） | 分批检测，单次不超过 50 种 |
| 中药/西药混合处方 | 分别按各自规则组审核 |

## EC-18: 网关限流边界

**场景**: Gateway Sentinel 限流特殊情况

| 边界 | 预期 |
|------|------|
| 突发流量超阈值 | 触发限流，返回 429 Too Many Requests |
| 限流期间 VIP 用户 | 可配置豁免（高优先级规则） |

| 网关与下游服务超时 | 网关超时 > 下游超时（默认 30s vs 10s） |
| 跨域 OPTIONS 预检 | 不校验 JWT，直接放行 |

## EC-19: 质控检测边界

**场景**: 质控统计的特殊情况

| 边界 | 预期 |
|------|------|
| 统计周期内无数据 | 返回空统计，不触发预警 |
