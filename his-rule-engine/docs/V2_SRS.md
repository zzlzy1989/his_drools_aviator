# HIS 动态规则中台 V2.0 需求规格说明书

> 文档版本: v2.0
> 创建日期: 2026-05-01
> 文档状态: ✅ 已完成 (2026-05-19)
> 适用项目: his_drools_aviator V2.0

---

## 1. 概述

### 1.1 项目背景

V1.0 已完成核心功能开发，实现了规则管理、公式管理、医保结算、合理用药、质控、DRG分组等7个微服务，并通过Docker Compose完成部署。

V2.0将在V1.0基础上进行增强，实现规则可视化编排、测试沙箱、监控大屏、规则市场等高级功能，提升用户体验和运营效率。

### 1.2 项目目标

| 目标 | 量化指标 |
|------|---------|
| 规则编排效率 | 可视化拖拽使规则创建时间减少50% |
| 规则测试效率 | 测试沙箱使规则上线前问题发现率提升80% |
| 系统可观测性 | 监控大屏使问题定位时间减少60% |
| 规则复用率 | 规则市场使跨医院规则复用率提升40% |

### 1.3 V1.0 vs V2.0 对比

| 维度 | V1.0 | V2.0 |
|------|------|------|
| 规则创建 | DRL代码手动编写 | 可视化拖拽+代码混合 |
| 规则测试 | 单元测试手动编写 | 沙箱环境+批量测试 |
| 规则监控 | 无 | 实时监控大屏 |
| 规则共享 | 无 | 规则市场模板库 |
| 规则回滚 | 无 | 版本对比+一键回滚 |

### 2.1 规则可视化编排模块

#### 2.1.1 功能列表

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|:------:|
| V2-R01 | 规则流画布 | 拖拽式规则流设计器，支持节点放置、连线、属性配置 | P0 |
| V2-R02 | 节点类型 | 支持条件节点、动作节点、公式节点、子流程节点 | P0 |
| V2-R03 | 规则流执行 | 解析规则流定义，串联执行多个规则/公式 | P0 |
| V2-R04 | 规则流版本管理 | 版本记录、版本对比、版本回滚 | P1 |

| V2-R06 | 规则流发布 | 语法校验后发布，自动刷新执行引擎 | P0 |

#### 2.1.2 节点类型定义

**条件节点 (ConditionNode)**
```json
{
  "type": "condition",
  "label": "患者类型判断",
  "expression": "patientType == 'RESIDENT'",
  "branches": {
    "true": "居民医保流程",
    "false": "职工医保流程"
  }
}
```

**动作节点 (ActionNode)**
```json
{
  "type": "action",
  "label": "计算报销金额",
  "ruleKey": "rule.reimburse.calculate",
  "timeout": 5000
}
```

**公式节点 (FormulaNode)**
```json
{
  "type": "formula",
  "label": "封顶线校验",
  "formulaKey": "formula.reimburse.capping",
  "params": {
    "amount": "${input.totalFee}",
    "cap": "${config.annualCap}"
  }
}
```

**子流程节点 (SubFlowNode)**
```json
{
  "type": "subflow",
  "label": "合理用药审核",
  "flowId": "drug-review-flow-v1",
  "async": false
}
```
